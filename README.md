# Экспертный разбор для JLC — сайт

Одностраничный сайт, адаптирован под телефон. Без сборки: только `index.html` и папка `img/`.

## Как опубликовать на GitHub Pages (бесплатно)

1. Зайдите на github.com → **New repository** → имя, например `jlc-razbor` → **Public** → Create.
2. На странице репозитория: **Add file → Upload files** → перетащите всё содержимое этой папки (`index.html`, `img/`, `.nojekyll`, `README.md`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/jlc-razbor/`.

## Контакты для кнопки встречи

В конце `index.html` найдите блок `CONTACTS` и впишите Telegram / WhatsApp / телефон / почту. Пустые поля не показываются.
